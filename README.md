# 浙江省高等学校教师教育理论刷题 APP

本地运行的刷题小应用：读取项目目录下的 Excel 题库，在浏览器中练习、统计错题，并可选使用 DeepSeek 生成错题解析（解析与编辑内容保存在本机浏览器）。题库来源：https://zhuanlan.zhihu.com/p/339958603

## 功能概览

- **断点练习**：每个题库保存一份未完成队列，首页点击「继续上次练习」恢复原顺序。提交后从下一题继续，未提交则回到当前题（未提交的选项不保存）。新开一轮会确认是否替换该题库断点。
- **优先刷完整库**：默认「未做题优先」，先随机排列未提交过答案的题，再排列已做题，最后按本轮题数截取；整库、分类和错题练习均适用，也可选择只练未做题或全部随机。继续上次练习保留原队列顺序。
- **练习分类**：记忆题、理解题、单选题、多选题、判断题。前两类依据内容匹配的新版 AI 解析，尚未解析的题只归入对应题型。两组分类有交叉，数量不可直接相加。首页显示待 AI 判定数量。
- **日间 / 夜间模式**：页面顶部切换，偏好保存在当前浏览器。
- **模拟组卷**：每卷随机抽取 40 道单选、20 道多选、20 道判断，总分 100 分；单选和判断每题 1 分，多选每题 2 分且必须完全正确才得分。70 分及格，按题库记录最近成绩和累计通过率；中途暂停后可继续。
当前使用 2026 年题库，共 2174 题：大学心理学 516 题、教师伦理学 650 题、高等教育学 449 题、高等教育法规与政策 559 题。题库文件名保留年份，以区分旧题号对应的浏览器练习记录。

分类归档由本地关键词规则生成，未调用 AI API，可能存在误分类；「多选全选题」依据题库答案整理，并不代表见到某个关键词就一定全选。

- **多题库**：自动扫描同目录下所有 `.xlsx` 文件作为题库。
- **题型**：单选题、多选题、判断题（由表格中的题型与答案列自动识别）。
- **刷题模式**：整库随机顺序；可「只练错题」；可限制「本轮最多几题」；可随时「结束」本轮。
- **知识分类练习**：后端优先读取 `question_categories.json` 中的逐题归档，首页可选择某一分类集中练习，适合把相似题放在一起记忆。
- **多选全选题专项**：所有正确答案覆盖全部选项的多选题会单独归入「多选全选题」，便于集中练全选套路。
- **记忆提示**：提交答案后会根据题型和题干关键词给出速记提示，例如多选题的全选、排除一项、同类列举、否定反选等套路。
- **熟悉度热图**：可按单选、多选、判断筛选；蓝→红表示逐题正确率由高到低，悬停可查看正确率与作答次数。历史上只记录是否做过、没有逐次答案数据的题会显示「暂无正确率」。热图上方另列出各题型总体正确率。
- **错题本**：独立页面，记录每题错题次数与时间；支持 DeepSeek 解析（Markdown 渲染）、本地缓存、手动编辑与保存。
- **数据不落服务器**：错题、做题痕迹、API 配置、AI 解析等均保存在浏览器 `localStorage`，Python 服务只负责读 xlsx 与提供静态页。

## 环境要求

- Python 3.9+（建议 3.10+）
- 依赖见 `requirements.txt`（FastAPI、uvicorn、pandas、openpyxl）

## 快速开始

macOS 可双击桌面的「启动题库.command」。启动器位于项目的 `launch.command`，固定访问 `http://127.0.0.1:8000/` 并复用已启动的服务；新启动服务时需保持终端窗口打开，按 Ctrl+C 可停止。移动项目目录后需修改启动器的 `PROJECT` 路径。`.bat` 是 Windows 脚本，macOS 使用 `.command`。

推荐双击桌面的「启动题库.app」，它通过 `scripts/launch_quiz.applescript` 调用启动器的后台模式，不经过 zsh 登录配置，不会被 oh-my-zsh 更新询问打断，也无需保持终端窗口。关闭浏览器不会停止后台服务，重启电脑后需再次启动。

在项目根目录（与 `server.py`、题库 `.xlsx` 同级）执行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

浏览器访问：**http://127.0.0.1:8000**

也可使用：

```bash
.venv/bin/uvicorn server:app --host 127.0.0.1 --port 8000
```

## 题库文件约定

- 将题库 Excel 放在与 `server.py` **同一目录**。
- 默认读取每个文件的第一个工作表，**至少两列**：第一列为题干（含编号、题型与选项文本），第二列为答案（单选为 `A`–`E`，多选为字母组合，判断为 `对` / `错`）。
- 文件名（不含扩展名）即题库在界面中的显示名。
- 题目分类不写回 Excel，而是保存在 `question_categories.json` 中，结构为“题库名 → 题号 → 分类名”。
- 如需重新生成分类，可运行 `scripts/generate_question_categories.py`；后端会优先读取 `question_categories.json`，文件缺失时才使用 `server.py` 中的兜底关键词规则。

## 前端依赖（CDN）

页面通过 jsDelivr 加载 **marked** 与 **DOMPurify**，用于安全渲染 AI 返回的 Markdown。离线或内网环境需自行改成本地脚本或镜像地址。

## 浏览器本地存储键（便于备份或清理）

### 跨浏览器迁移

1. 在原浏览器打开「设置与备份」，点击「导出备份」，保留下载的 JSON 文件。
2. 在 Safari 或 Chrome 打开 `http://127.0.0.1:8000/`，进入「设置与备份」，选择该文件。
3. 核对预览数量，点击「确认合并导入」。API 密钥和配置不随备份迁移，需要在目标浏览器另行设置。

备份包含做题痕迹、错题统计、逐题正确率、练习断点、模拟考试成绩和未完成试卷、旧版文本解析、新版文本解析和结构化解析。导入补充缺失项；已有解析优先，同题错题次数及最近时间分别取较大值，正确率计数分别取较大值，模拟考试成绩按时间合并并保留最近 100 次。题库按完整名称、题号保留，不跨年份混合记录。各浏览器仍独立存储，不会自动同步。批量解析进行中需先停止再导入。

| 键名 | 用途 |
|------|------|
| `quiz_bank_stats_v1` | 各题库错题次数与时间 |
| `quiz_question_seen_v1` | 各题是否已在应用内提交过答案（用于热图灰色） |
| `quiz_answer_stats_v1` | 各题累计答对、答错次数（用于热图正确率） |
| `quiz_ai_analysis_v1` | 各题 AI 解析正文（可编辑后覆盖保存） |
| `quiz_deepseek_cfg_v1` | DeepSeek API Key、Base URL、模型名 |

更换浏览器、清除站点数据或使用不同端口访问时，上述数据不会自动迁移。

## DeepSeek 说明

- 「测试 API」使用一条内置示例检查已保存的配置，不运行全题库；失败时会区分超时、输出截断、JSON 格式和字数超限。批量状态保留本轮最近失败的题号和原因。官方 DeepSeek 请求采用非思考模式和 2048 token 输出上限，正文仍限制为 100 字。

- 在「API 设置」点击「开始 / 继续解析全部题目」，按当前配置逐题调用 API（会消耗 API 额度）。保持页面打开；可停止，重新开始会跳过已成功解析且题目内容未变的记录，失败项会重试。
- 新版解析区分「记忆题」和「理解题」，正文不超过 100 字。记忆题可附不超过 30 字的联想记忆点；答案冲突或依据不确定的题目会标记待核对。
- 新版结构化解析保存在浏览器 `quiz_structured_analysis_v2`，手动编辑文本保存在 `quiz_ai_analysis_text_v2`。旧版缓存保留但不作为新版解析使用。未生成的题目不会被声称为已分类；批量分类属于 AI 判断，仍需复核。

- 在「API 设置」中填写 Key 等并保存后，请求从**浏览器直连** `https://api.deepseek.com`（或你填写的 Base URL）。
- 已生成并保存的解析默认不再请求接口，可节省调用次数。
